# Стенограф

Локальный диктофон: речь → задачи → протокол → карта.

Выгрузка на GitHub идёт пакетами (лимит API). Сейчас в репо: типы, классификатор, речь, микрофон, Whisper, WASM/WebGPU, часть UI.

Полная студия (с store, настройки, встречи) работает в превью Grok. `npm start` из клона открывает стартовую страницу на :4173.
