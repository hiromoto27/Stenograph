# Стенограф

Локальный нейросетевой диктофон: запись с микрофона, разбор речи по задачам, протоколы, напоминания и mind-карта.

Исходники модуля: `src/components/stenograf` и `src/lib`.

## Что умеет

- Запись по запросу и постоянная (с индикатором)
- Выбор устройства ввода, уровень сигнала
- Фразы «сделай задачу», «необходимо», «напомни завтра в 10» создают задачи и сроки
- Самообучение: уточняет, к какой задаче отнести реплику
- Удаление строк из ленты распознавания и из готового протокола
- Карта связей: на узлах только выжимка (ключевые фразы), связи можно добавить и убрать кликом
- Напоминания: правка времени, отложить, повторить
- Локальные модели MiniLM / E5 скачиваются в кэш браузера

## Карта и протокол

- В ленте у каждой реплики кнопка **Удалить**.
- В протоколе у пунктов «убрать» — удаляет строку из уже собранного текста.
- На карте под названием задачи — суть, не полный диалог.
- Выберите задачу → «Связать с…» + подпись. Клик по ребру скрывает связь.
