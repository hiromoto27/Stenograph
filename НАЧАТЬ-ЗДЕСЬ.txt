СТЕНОГРАФ — НАЧНИТЕ ЗДЕСЬ

УСТАНОВКА БЕЗ POWERSHELL

1. Распакуйте ZIP-архив целиком.
   Откройте папку, в которой виден файл Установить.cmd.
   Не запускайте файлы из открытого ZIP-архива.

2. Дважды щёлкните Установить.cmd.
   Понадобится интернет. Дождитесь слова ГОТОВО.
   Если текст продолжает появляться — установка ещё идёт.
   В конце нажмите любую клавишу, чтобы закрыть окно.

3. Дважды щёлкните Подготовить-речь.cmd.
   Дождитесь слова ГОТОВО. Модель речи скачается и выберется сама.
   Это нужно сделать один раз. Первый раз нужен интернет.

4. Дважды щёлкните Запустить.cmd.
   Создайте новую встречу → выберите микрофон → нажмите Записать.
   Для собеседников из онлайн-встречи выберите также Звук встречи.
   После разговора нажмите Стоп и дождитесь расшифровки.

ПРОТОКОЛЫ И АВТОМАТИЧЕСКИЕ ЗАДАЧИ

Для этой части нужен Ollama — программа, которая запускает модель локально.

1. Скачайте и установите Ollama: https://ollama.com/download/windows
2. Откройте установленный Ollama.
3. Если СтеноГраф открыт, завершите его через значок в трее:
   правой кнопкой по значку → Завершить.
4. Дважды щёлкните Подготовить-протоколы.cmd. Дождитесь ГОТОВО.
5. Откройте Запустить.cmd. После расшифровки встречи нажмите
   Создать протокол и задачи.

Ollama должен оставаться запущенным для создания протокола.
Подготовка скачивает модель через интернет; после неё можно работать офлайн.

ЕСЛИ УСТАНОВКА НЕ УДАЛАСЬ

Рядом с Установить.cmd появится файл install.log.
Пришлите его целиком — в нём сохранена причина ошибки.
Для ошибки подготовки моделей пришлите скриншот окна.
Не вводите отдельно -File и не запускайте файлы через PowerShell.

PYTHON

Поддерживаются обычные Python 3.11, 3.12 и 3.13 для Windows x64.
Установщик сам ищет уже установленный Python.
Если подходящего нет, установите Python 3.12 x64 с python.org,
отметив Add python.exe to PATH. Текущий Python удалять не нужно.
Python 3.14+, 32-bit, ARM64 и free-threaded пока не поддерживаются.

ВАЖНО ДЛЯ ПЕРВОЙ ПРОБЫ

Это ранняя версия. Windows-запись и сборка EXE ещё требуют проверки
на реальном компьютере. Исходники и проверки описаны в README.md.
Для теста онлайн-встречи используйте наушники, чтобы уменьшить повтор звука.
Напоминания работают при запущенном СтеноГрафе, в том числе в трее.

НОВОЕ В 0.2
Подробная инструкция: откройте stenograph\resources\help.html в браузере
или раздел «Обновления и помощь» внутри приложения.

Без Ollama: закройте приложение → Подготовить-встроенную-модель.cmd →
дождитесь ГОТОВО → Запустить.cmd. Нужен интернет только для подготовки.

Обновления: кнопка «Проверить обновления» в приложении.
Первый переход с 0.1: распакуйте 0.2 в новую папку и выполните Установить.cmd.
Не удаляйте прежнюю папку моделей: сохранённые настройки могут ссылаться на неё.

Аудио удаляется через час после успешного протокола, при работающем приложении.
Для сохранения оригинала скопируйте его заранее. Тексты и задачи остаются.

Mind-карта: + Добавить элемент; двойной щелчок — редактор и «Достроить».
Кнопка «Связи…» — создать, изменить направление/подпись или удалить связь.
