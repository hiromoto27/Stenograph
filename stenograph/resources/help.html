Протоколы через Ollama: один раз настроить, затем пользоваться офлайн

Модель речи превращает звук в текст. Другая модель читает текст и составляет протокол. Для неё можно выбрать Ollama либо встроенный движок.

  1. Установите Ollama для Windows и откройте его через меню «Пуск». Это отдельная программа, которая должна работать в фоне.
  2. Закройте СтеноГраф: значок приложения рядом с часами → «Завершить». Обычный крестик может свернуть его в трей.
  3. В папке СтеноГрафа дважды щёлкните Подготовить-протоколы.cmd. Дождитесь «ГОТОВО». Нужен интернет для загрузки нескольких гигабайт; модель подбирается по памяти ПК.
  4. Откройте Запустить.cmd. В «Модели и компьютер» выбран режим Ollama. Кнопка «Проверить подключение к Ollama» на этой странице проверяет сервер и наличие выбранной модели.
  5. Создайте встречу, запишите разговор, остановите запись и дождитесь распознавания очереди. Нажмите «Создать протокол». Передавать текст вручную в окно Ollama не нужно.
  6. Проверьте выводы по цитатам. Задачи из протокола появляются черновиками: задайте статус «В работе» и время напоминания.

При следующих запусках достаточно открыть Ollama и СтеноГраф. Повторная загрузка моделей не нужна. Для локальной работы интернет можно отключить.

Если не получилось

  • Сервер недоступен / connection refused: откройте Ollama из «Пуска», подождите и проверьте снова. В командной строке можно выполнить ollama list; если сервер не запущен — ollama serve и оставить это окно открытым. Сообщение «port already in use» обычно означает, что сервер уже работает.
  • Модель не найдена: выполните подготовку ещё раз. В «Модели и компьютер» имя должно совпадать с установленным: qwen3:1.7b, qwen3:4b или qwen3:8b. После смены нажмите «Сохранить настройки».
  • Не хватает памяти / слишком медленно: выберите qwen3:1.7b; для загрузки откройте cmd и выполните ollama pull qwen3:1.7b. Затем выберите это имя в СтеноГрафе и сохраните настройки.
  • ollama не является командой: закройте и заново откройте cmd после установки. Файл «Подготовить-протоколы.cmd» также ищет Ollama в стандартной папке установки.
  • Ошибка формата ответа или цитаты: протокол не сохранится частично; текст останется. Повторите анализ или попробуйте более крупную модель, если хватает памяти.

СтеноГраф обращается к Ollama по адресу 127.0.0.1:11434 на вашем ПК. Сетевые функции самой Ollama настраиваются отдельно. Для отключения её облачных функций добавьте пользовательскую переменную Windows OLLAMA_NO_CLOUD со значением 1 и полностью перезапустите Ollama.

Встроенная модель: без отдельной Ollama

  1. Закройте СтеноГраф через трей.
  2. Откройте Подготовить-встроенную-модель.cmd. Скрипт установит готовый CPU-пакет llama-cpp-python и скачает Qwen2.5 1.5B Instruct GGUF (~1.12 ГБ). Если для вашего Python нет готового пакета, используйте Ollama или установку на Python 3.12 x64.
  3. После «ГОТОВО» запустите приложение. В настройках автоматически выбран встроенный движок и путь к GGUF. Создание протоколов теперь не требует отдельного сервера.

Это компактная модель: качество сложных протоколов может быть ниже, чем у крупных моделей. Нужна свободная оперативная память сверх размера файла. Модель загружается на время анализа и освобождается после него. Можно выбрать другой локальный GGUF семейства Qwen2.5 Instruct; произвольные архитектуры и форматы чата не поддерживаются. Встроенный режим пока использует CPU.

Mind-карта: расширение знаний вручную

Нажмите «+ Добавить элемент», задайте раздел, тему и содержание. Двойной щелчок по ручной заметке открывает редактор: можно изменить текст, перенести её в другой раздел/тему или встречу и нажать «Достроить», чтобы добавить связанный элемент.

Кнопка «Связи…» позволяет связать любые две ручные заметки, изменить направление, конечные элементы и подпись. Двойной щелчок по золотой связи также открывает редактор. Удаление связи сохраняет элементы; удаление элемента убирает только его собственные связи. Ручные записи и связи не заменяются повторной генерацией протокола. В карте одной встречи показываются связи внутри неё; включите «Все встречи», чтобы видеть межтематические связи. Автоматические факты сохраняют привязку к цитатам; их содержание исправляется через расшифровку и новый протокол.

Напоминания и очистка

В задаче есть быстрый выбор «Через 15 мин», «Через час», «Завтра 09» и «За 15 мин до срока». В уведомлении можно отложить задачу, отметить выполненной или закрыть уведомление. Приложение должно работать, в том числе в трее. При выключенном ПК напоминание появится после запуска.

Через час после успешного создания протокола удаляются обработанные аудиофрагменты этой встречи. Проверка выполняется раз в минуту, пока приложение работает; после выключения — при следующем запуске. Ошибочные и ещё не распознанные записи сохраняются. Текст, протокол, задачи и скриншоты остаются. Для старых записей версии 0.1 отсчёт начнётся после повторного создания протокола. Если оригинальное аудио нужно сохранить, скопируйте его заранее.

Обновление

Нажмите «Проверить обновления», затем «Установить обновление». Подтвердите показанную версию и репозиторий. Приложение закроется, откроется окно обновления. После «ГОТОВО» запустите его снова. Источник по умолчанию: hiromoto27/Stenograph, ветка main. Ветка должна содержать готовый выпуск с release.json и более высоким номером версии.

Обновление предназначено для установки из исходников через CMD на Windows. Для первого перехода с 0.1 распакуйте 0.2 в новую папку и запустите «Установить.cmd»; данные подхватятся из прежней папки профиля. EXE обновляется отдельной загрузкой новой сборки. Проверяются контрольные суммы; изменённые вручную программные файлы не перезаписываются. Предыдущие исходники сохраняются в папке данных/update-backups. При ошибке установки зависимостей исходники откатываются; зависимости могут требовать повторного запуска «Установить.cmd».

Проверка обновлений обращается к GitHub, установка зависимостей — к источникам пакетов. Содержимое встреч при этом не отправляется. При отключённом интернете запись, поиск, карта и подготовленные модели продолжают работать.
